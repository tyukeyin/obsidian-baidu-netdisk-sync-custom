# 百度网盘同步：本地定制版

基于 owl234/obsidian-baidu-netdisk-sync 1.0.13（8b4e03b）修改，版本 1.0.14-local.2。不是上游官方发布。

## 五种方向

在插件设置的「3. 存储与目录规划」中选择「同步方向（仅此设备）」。

| 方向 | 行为 |
| --- | --- |
| 双向同步 | 保留上游逻辑：新增、修改、删除双向传播；并发修改按时间戳裁决。 |
| 仅发送 | 上传本地新增及修改；保留云端独有、独立修改或独立删除的内容，不传播删除。 |
| 仅发送：覆盖云端变更 | 以本地为准，覆盖云端差异、恢复云端被删文件、删除云端独有文件。 |
| 仅接收 | 下载云端新增及修改；保留本地独有、独立修改或独立删除的内容，不传播删除。 |
| 仅接收：还原本地变更 | 以云端为准，覆盖本地差异、恢复本地被删文件、删除本地独有文件。 |

普通单向模式中，没有同步历史的同名文件会跳过；日志说明原因。来源端修改而目标端未修改时才覆盖。跳过不会更新该文件的同步基线。切回双向后，仍会按原有历史处理差异，包括删除。

覆盖/还原是镜像操作，仅接受手动触发，每轮展示完整操作清单并确认；自动触发会跳过。预览后再次扫描，检测到变化则中止。过滤规则始终生效，镜像范围仅包括参与同步的文件。目录空壳不作为镜像对象。

方向仅保存在本设备插件配置，配对导出不会携带方向。插件自身文件也不通过本插件同步，所以其他设备需分别安装本定制版。

## 安装与回退

等待当前同步完成，关闭 Obsidian。将安装包中 baidu-netdisk-sync 文件夹内的 main.js、manifest.json、styles.css 放入目标库 .obsidian/plugins/baidu-netdisk-sync，替换同名文件。保留该设备原有 data.json 与 sync_manifest.json，不从另一台设备复制它们。

重新打开 Obsidian，在设置中选择本设备方向。旧配置缺少方向时默认双向。本次只替换程序文件，没有主动同步正式库。

更新上游版本可能覆盖本地改动。回退时关闭 Obsidian，用原版备份的三个文件覆盖；原版没有方向功能，会恢复双向同步。回退前可先在设置中关闭自动同步。

## 每次手动选择
手动点击同步（侧栏、命令面板、日志窗口）均先选择本次方向。记住上次手动选择，仅用于下次弹窗默认值，不改变自动同步方向。取消不会扫描或传输。自动同步仍按设置中的方向运行；覆盖/还原仍需手动执行和清单确认。

## 1.0.14-local.3：内容校验

本地扫描计算内容 MD5，网盘端优先比较服务器 MD5。建立内容基线后，单纯修改时间不触发传输；同大小、同时间但内容不同也能检测。MD5 用于变化检测，不作安全认证。

本地原文指纹与网盘文件指纹分开保存，兼容加密文件。旧记录只在指纹吻合时补齐；缺少可靠指纹时保留时间/大小回退，首次升级可能仍有传输。每轮读取本地文件计算指纹，减少无效传输但增加本地扫描开销；网盘不返回 MD5 时仍回退原判断。

回归测试覆盖时间变化但内容相同、同时间同大小内容改变、五种策略及网盘指纹变化。未连接真实网盘进行测试。

## 1.0.14-local.4：目录迁移与同步完整性

正常双向同步按完整相对路径处理新增、移动/改名与删除。当前采用「先传输新路径，再删除旧路径」，不因为内容相同而省略新路径文件。暂未使用服务端重命名或跨路径文件复用。

- 新路径支持逐级创建父目录，下载后读取校验落盘内容。
- 所有传输成功且历史已保存后，才开始清理旧路径。失败保留旧副本，下次重试；删除前再次核对云端列表及本地内容。
- 删除文件后只清理它的空父目录；不清理库根目录、配置目录或含排除文件的目录。不会全库批量删除空文件夹，也不递归删除云端目录（避免误删并发新增文件）。历史遗留且已失去记录的空目录不自动识别为垃圾。
- 云端列表缺失、请求出错或同步历史读写失败时停止，不将异常当作正常空库。
- 保存后自动同步新增 rename 监听；同步期间的改动保留待处理标记，空闲后补跑。失败等待下一次触发，避免限流重试风暴。

各设备如需编辑后自动同步，请启用「保存后同步」并使用双向模式，延迟建议 5 秒。自动同步开关保留各设备原有设置；云端变化仍由启动或定时同步获取。Obsidian 关闭时插件不运行。
